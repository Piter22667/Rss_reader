# Порівняння локальної та хмарної моделі

Python 3, без сторонніх бібліотек. Проєкт і база не змінюються.
Файли inputs — копії трьох наданих статей; article_id 1–3 — тестові ID.

## Запуск

1. Розпакуйте всю папку, відкрийте PowerShell у ній.
2. Запустіть Ollama; модель `lfm3:1.7b` має бути завантажена.
3. Виконайте:

```powershell
py -X utf8 compare.py
```

Якщо OPENROUTER_API_KEY не задано, скрипт попросить ввести ключ приховано.
Ключ не записується в код, запити на диску чи таблиці. Не надсилайте його в чат.
Хмарні запити оплачуються з вашого балансу. Звичайний запуск робить
6 локальних і 6 хмарних запитів без автоматичних повторів; повторний запуск
створює новий набір. Ctrl+C припиняє роботу; попередні результати залишаються.

За бажанням ключ можна передати через змінну середовища OPENROUTER_API_KEY.
Не додавайте його до файлів, що потраплять у Git або на скріншоти.

## Варіанти

```powershell
# Без мережі та витрат: тільки сформувати 12 запитів
py -X utf8 compare.py --dry-run

# Перевірити підготовку й валідатор без мережі
py -X utf8 check_setup.py

# Лише один сервіс (6 запитів)
py -X utf8 compare.py --providers local
py -X utf8 compare.py --providers openrouter
```

Моделі за замовчуванням: lfm3:1.7b і openai/gpt-6-luna (ідентифікатор
хмарної моделі наданий користувачем). Невідомий ID або відсутність доступу
не спричиняє підміни моделі: запит завершиться помилкою. Інший ID:

```powershell
py -X utf8 compare.py --cloud-model organization/model
```

## Умови

Обидва сервіси отримують ідентичні system/user messages для відповідної статті
й варіанта тексту. System prompt — незмінений файл із проєкту, без додаткових
правил і без примусового JSON: немає ані format, ані response_format.
Очікується початковий масив з одним об'єктом, як зазначено у промпті.

Мова українська, нейтральний стиль, 40–70 слів, без додаткових побажань,
temperature=0, ліміт генерації 1024 токени. Ollama: контекст 8192, think=false.
Хмарна модель використовує власні налаштування контексту/міркування; ці умови
не є ідентичними. Підтримку параметрів і доступність ID визначає провайдер.
Це зіставлення з промптом проєкту, а не повне відтворення всіх його API-параметрів.

raw — повний Markdown; cleaned — автоматично виділена основна стаття.
Очищення спеціально налаштоване на ці приклади РБК: між блоком додавання
джерела Google та підпискою «Не пропустіть», без кінцевих пов'язаних новин.
Зберігається блок «Оновлено». Це не універсальне рішення для інших сайтів.

## Результати

Нова папка results для кожного запуску містить:

- *_request.json — точні тіла запитів без ключа;
- *_response.json — повні API-відповіді з метаданими/usage, якщо надані;
- *_answer.txt — незмінений текст моделі для перегляду та скріншотів;
- *_checks.json — час, структура, кількість слів, помилки й ознака обрізання;
- comparison.md — зведена таблиця;
- evaluation.csv — та сама таблиця з порожніми полями ручного оцінювання.

Ручні поля: facts_manual, coverage_manual, ukrainian_manual, notes_manual.
Пишіть «так/частково/ні» та конкретний приклад. Порожнє поле не означає успіх.
Перевіряти факти треба за наданими файлами; їхні новинні твердження окремо
не перевірялися. Початкові умови для перевірки:

1. Допомога близько 15 млрд лише обговорюється; не називати вже наданою.
2. Обмеження додаткових поставок Patriot зараз — не припинення всієї допомоги.
3. У тексті про Краків є 6 загиблих і оновлення про 12 постраждалих.

Валідатор лише оцінює відповідь, не ремонтує JSON та не змінює текст.
Перевірку HIDDEN ці приклади не покривають. Кількість слів рахується за
пробілами. Тривалість включає мережу, завантаження моделі та вплив кешу:
один запит на комбінацію — попередня оцінка, не бенчмарк швидкодії.

HTTP-помилки 401/402/403/404 зупиняють запуск. Перевірте доступ, баланс і ID
моделі; для решти помилок скрипт записує збій та переходить до наступного запиту.

API: https://openrouter.ai/docs/api-reference/overview
